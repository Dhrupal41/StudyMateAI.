# 🎓 StudyMate AI

### Your AI-Powered Personal Learning Assistant

StudyMate AI is a student-focused learning application built using Python and Streamlit. It helps students understand concepts, generate study notes, practise quizzes, ask questions and explore career paths through an interactive web interface.

## ✨ Features

### 📚 Learning Studio
- Explain difficult topics in simple language.
- Generate structured study notes.
- Create interactive quizzes.
- Review answers and quiz scores.

### 📄 PDF Notes
- Generate organised study notes.
- Download notes as PDF documents.

### 🤖 Chat Tutor
- Ask educational questions.
- Receive explanations and learning assistance.
- Interact through a chat interface.

### 🚀 Career Roadmap
- Explore different career options.
- Generate career learning roadmaps.
- Follow a structured learning plan.
- Download roadmaps.

### 🎨 User Interface
- Modern dashboard.
- Interactive navigation.
- Dark-themed design.
- Student-friendly interface.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Dhrupal41/StudyMateAI.git
```

### 2. Open the project folder

```bash
cd StudyMateAI
```

### 3. Create a virtual environment

```bash
python3 -m venv .venv
```

### 4. Activate the environment

```bash
source .venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure your API key

If your current version uses the OpenAI API, create a `.env` file and add your API key:

```env
OPENAI_API_KEY=your_api_key_here
```

Never upload your real API key to GitHub.

### 7. Run the application

```bash
python -m streamlit run app.py
```
